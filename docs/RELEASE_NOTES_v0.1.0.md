# TouchLockButtons v0.1.0

Initial public, experimental release for Kindle Paperwhite 4.

Highlights:

- five-button bottom bar that reserves reading space;
- separate virtual-bar lock and full-touchscreen state;
- centered touch-state indicator;
- dedicated sleep button;
- optional Power-button navigation;
- triple-click touchscreen toggle;
- mandatory activation warning;
- click-window configuration;
- resume and popup touch-lock recovery.

Use the attached `touchlockbuttons.koplugin-v0.1.0.zip` asset for installation. Do not use GitHub's automatically generated source archive as the install package.
